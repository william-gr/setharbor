Planejar com ChatGPT

Compartilhe um pedido curto com o ChatGPT. As instruções e o catálogo ficam nesta página; sua ficha, histórico e cargas não são enviados por este botão.

Depois de conversar, toque no link devolvido pelo ChatGPT para revisar e aplicar a ficha no SetHarbor já instalado.

Instruções para o ChatGPT

Pergunte objetivos, dias disponíveis e equipamentos antes de criar. Use os catalogIds exatos da tabela abaixo e adapte volume/repetições ao pedido. Ao revisar uma ficha enviada, preserve IDs de posições somente se o movimento permanecer igual. Não invente catalogIds. Se não puder consultar esta página ou executar a codificação, explique a limitação em vez de inventar um link.

Entregue um link clicável com o texto Abrir no SetHarbor, não uma solicitação para copiar JSON ou importar arquivo. Mostre também um resumo do treino para revisão. A ficha fica no fragmento do próprio link; não hospede a ficha do usuário nem envie histórico/cargas para esta página.

Contrato da ficha

  • format: meu-treino-plan; schemaVersion: 1; revision: inteiro positivo, maior que a revisão atual quando fornecida.
  • title: texto não vazio até 120 caracteres; days: 1–7 dias.
  • Dia: id único na ficha (até 80), name (até 80), focus opcional não vazio (até 200), exercises: 1–20 exercícios.
  • Exercício: id único na ficha inteira (até 80), catalogId da tabela, name (até 120), sets inteiro 1–10, reps texto não vazio (até 40).
  • id identifica a posição; catalogId identifica o movimento. O mesmo movimento em dias diferentes precisa de IDs de posição diferentes.
{
  "format": "meu-treino-plan",
  "schemaVersion": 1,
  "revision": 2,
  "title": "Teste ChatGPT · 3 dias",
  "days": [
    {
      "id": "link-day-0",
      "name": "Segunda",
      "focus": "Teste de integração",
      "exercises": [
        {
          "id": "link-slot-0",
          "catalogId": "barbell-bench-press",
          "name": "Supino reto barra",
          "sets": 2,
          "reps": "8–12"
        }
      ]
    }
  ]
}

Gerar o link de treino

Execute este código com o objeto plan validado. Use JSON UTF-8 completo e Base64URL sem padding. A URL completa tem limite de 64000 caracteres. Não use um encurtador ou link para baixar arquivo.

import base64, json
payload = base64.urlsafe_b64encode(
    json.dumps(plan, ensure_ascii=False, separators=(',', ':')).encode('utf-8')
).decode().rstrip('=')
url = 'https://william-gr.github.io/setharbor/open/#v1.' + payload
assert len(url) <= 64000

Retorne em Markdown: [Abrir no SetHarbor](URL_GERADA). O app valida e pede confirmação. Se abrir no navegador, a página oferece um botão para abrir o app. Treinos em andamento bloqueiam a troca; sessões anteriores são preservadas.
